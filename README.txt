# For You, Always ♡

## Website files
- `index.html`
- `style.css`
- `script.js`
- `assets/hero.png` (updated cinematic theme image)
- `assets/music/` (put your two audio files here)

## Add your songs
Copy your legally obtained audio files into `assets/music/` and rename them exactly:
1. `tamally-maak.mp3`
2. `cant-help-falling-in-love.mp3`

The website tries to start the first song automatically when the page loads. Modern browsers often block audible autoplay until the visitor interacts with the page. If blocked, the on-page play button appears as the manual fallback. After the visitor presses play once, the second song starts automatically when the first finishes.

## Deploy to GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. Keep the `assets` folder at the same level as `index.html`, `style.css`, and `script.js`. The relative paths are intentional and work under a project URL such as `https://username.github.io/loveu/`.

After deployment, hard-refresh with Ctrl+Shift+R.
